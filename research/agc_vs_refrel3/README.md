# AGC 3.2.4 vs refrel3 v1 on HPRC N = 50 (ace-core, CPU in process)

Set: the first 50 rows of the refrel3 v1 cohort manifest (`research/refrel/logs/cohort-v1-manifest-2026-10-04.tsv`),
= the 50 sets of `t2t_50.agc` / `noref_50.agc` (set names = manifest names without `y1_`). Truth: the 50 source
`.fa.gz` (SHA-256 == manifest `source_sha256`, all 50 checked), decoded by `truth.cpp` into SHA-256 of upper-case bases
per request and per sample (`truth_requests.tsv`, `truth_samples.tsv`). Every answer of every run (warm-ups included)
SHA-256 == truth: 384 + 8 runs, 0 mismatches. Measured 2026-10-05, ace-core (AMD EPYC 4344P, 8 cores / 16 threads,
125 GB), silence gates `logs/silence_gate.txt` (20:35 UTC, load 0.46) and `logs/silence_gate_all50.txt` (21:47 UTC,
load 0.49); nothing else ran during the runs; openhands / glyph recorded as background.

## Tools and provenance

- AGC in process: `agcbench.cpp`, C API `agc_get_ctg_seq` (0-based inclusive range; checked against the CLI and the
  FASTA) of `libagc.a` built from AGC source tag v3.2.4 (commit e67e3fc, `.wk/tools/agc-src`, its makefile: g++ -O3
  -march=native -std=c++20, `agc-build.log`), one handle per thread opened with `prefetching = 1` before timing. Whole
  samples: every contig of the sample (truth order) in full, contigs spread over the threads.
- AGC CLI: `agc_cli_batch.py`, the release binary that built the archives (`agc` 3.2.4 build 20260722.1), all requests
  of a run in one `agc getctg -t T` process; wall time of the process.
- refrel3 in process: `rr3bench.cpp` on aceapex research/refrel @ 5b6d5ce (sources unchanged in this tree), built from
  `refrel3v1_nomain.cpp` = `refrel3v1.cpp` with line 243 `int main(` -> `static int refrel3v1_main(` (sed), g++ -O3
  -march=native -funroll-loops; reference + 50 archives opened (every FORMAT.md section 5 check) before timing; windows
  / regions: the touched blocks decoded (`block_v1`); whole samples: every block, blocks spread over the threads.
  Output upper case (lower-case runs not applied: the truth is upper case).
- Requests: `make_requests.py` (contig tables of the archives; seeds 20261003 / 20261005): `windows_8192.tsv`,
  `regions.tsv`. Runner: `run_all.sh`. Binary SHA-256: `binaries.sha256`; archive SHA-256: `agc_archives.sha256`
  (refrel3: the manifest).
- First all-50 attempt: the bench held all 50 decoded samples in memory and was killed by the kernel (exit 137,
  `logs/*_sample50_*_oom_killed.log`); rerun with one sample in memory at a time (mode `each`; time = sum of the
  per-sample decode times).
- Differs in scope from the axis-3 D_Q run (hw-apex-bench 1351dcf, refrel3 q4k 0.876 GB/s one thread): that one rebuilt
  the FASTA with case runs (`full_v1`); here only the base stream is decoded (2.29 GB/s one thread).
